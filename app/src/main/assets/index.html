Masuk Ruangan LAN

Semua HP harus di WiFi yang sama. Tanpa login, tanpa server luar.

Akan gabung ke: -
Minta IP ke Host. Host bisa lihat IP-nya di layar chat setelah Buat Ruangan. Tidak perlu ketik titik dua (:) — IP dan Port sudah dipisah.
Cara pakai:
1. HP 1 tap Buat Ruangan, lalu bagikan IP-nya.
2. HP lain isi Nama + IP Host, tap Gabung.
3. Chat teks + foto langsung jalan. Host harus tetap buka aplikasi, riwayat hilang kalau Host tutup.
